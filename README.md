# Blackys-Eco-Resort-Resort-Management-and-Online-Reservation-System

**Blackys Eco Resort** is a web-based **Resort Management and Online Reservation System** developed to provide customers with an easy way to explore resort facilities and make reservations.

The system also includes an **Admin Dashboard** for managing reservations, rooms, offers, activities, gallery, and other resort information.

## ✨ Features

### 👤 Customer Side

* 🏠 View resort information
* 🛏️ Browse rooms and catalogue
* 📅 Make reservations
* 🎉 View offers and packages
* 🏊 Explore resort activities
* 🖼️ View image gallery
* 🍽️ View restaurant/menu
* 📞 Contact the resort

### 🔐 Admin Side

* Secure admin login
* 📊 Dashboard
* 📅 View and manage reservations
* ✏️ Edit reservation details
* 🛏️ Add, edit and delete rooms
* 🎉 Manage offers
* 🏊 Manage activities
* 🖼️ Manage gallery
* 🍽️ Manage menu
* 👥 Manage users

## 🛠️ Technologies Used

* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Backend:** PHP
* **Database:** MySQL
* **Server:** Apache
* **Development:** XAMPP
* **Database Management:** phpMyAdmin

## 🚀 How to Run

1. Install **XAMPP**.
2. Copy the project into:

```text
C:\xampp\htdocs\
```

3. Start **Apache** and **MySQL** from XAMPP.
4. Open phpMyAdmin:

```text
http://localhost/phpmyadmin
```

5. Create the project database and import the provided SQL file.
6. Configure the database connection in the PHP configuration file.
7. Open the website:

```text
http://localhost/blackys-eco-resort/
```

### 🔐 Admin Panel

```text
http://localhost/blackys-eco-resort/admin/
```
